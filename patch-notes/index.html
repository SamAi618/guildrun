How to read the patch history

Version 0.5.4 should be read together with versions 0.5.1 through 0.5.3 when checking an older guide. Balance changes can alter hero tuning, Red Rift behavior, and the result of a recorded build. A video from an earlier patch remains evidence for its own version, not automatic proof for the current one.

Record the patch beside every tier placement, build recommendation, or leaderboard claim. Developer rationale can explain why a value changed, while community results show how that change appeared in runs. Future patch values beyond the collected notes remain 待确认.

The official Steam news hub is the version-sensitive source for announcements and balance history. As collected on August 14, 2026, the demo has weekly updates and the current public notes reach version 0.5.4. The demo is available now, while the full release has only a developer target in the first half of 2027 and no exact launch date.

Evidence and update policy

The material set was collected on August 14, 2026, so every current-status statement is bounded by that date. Official Steam or Leyline wording has priority for availability, release timing, supported platforms, and version numbers. A community post can preserve context, but it cannot create an official announcement. A gameplay video can show what one build did, but it cannot confirm a release schedule or an unpublished patch.

When an official page and an older guide differ, use the dated official update for the current status. Keep the exact distinction between a Demo, a developer target, a patch number, and the full release. Do not infer an exact date from a broad window such as the first half of a year. Do not infer an unlisted platform merely because the game supports another desktop operating system.

Do not infer a future feature from a community request or creator prediction. If the official wording changes after collection, the older statement becomes historical context rather than current guidance. Dates, counts, and version labels should remain attached to the source that supplied them. Anything outside those boundaries is marked 待确认 instead of being filled with a plausible guess.
