Guildrun Release Date

When will the full Guildrun game release?

The free demo launched on July 16, 2026. The full game does not have an exact announced date. Developer communication in the first demo patch says the team is aiming for the first half of 2027 and will discuss a firmer launch date closer to 2027; that target should not be presented as a guarantee.
